# Rendering ownership in Gnozian Remastered

The map uses the Babylon.js engine in src/components/GameCanvas.tsx for
drawing, picking, camera and HiDPI scaling.

The old Canvas2D renderer and Renderer3D shim were unreferenced.
The separate mapRenderer, renderFacade and visualRemasterRenderer stack
remained in boot preloads despite not being used for the current map.
These obsolete paths are removed instead of maintained as parallel
renderers. The actual gameplay effects in visualFxPipeline.ts are kept.

The remastered UI loads standalone SVG assets generated by
scripts/generate2dAssets.mjs. Don't reintroduce retired graphics
stacks in place of improving the real Babylon scene and UI.
